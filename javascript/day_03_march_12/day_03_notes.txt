Window Object methods
=====================
alert() : Display Informational Message
          Message + Ok

confirm() : User Confirmation
            Message + (Ok-true , Cancel-false)

prompt() : To Collect User input
           Message + InputBox + Ok,cancel            

Note: Window object methods can be used directly.
      window.alert()  // valid
      alert();        // valid

undefined vs null
===================
-when a variable is declared without any value, javascript assigns 'undefined' to that variables
-null is an intentional value assigned by developers.
-typeof 'undefined' value is undefined, type of 'null' value is object
